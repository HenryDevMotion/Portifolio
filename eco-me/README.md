# Eco-Me

Este é um CLI simples em Node.js para registrar e organizar objetivos e ideias.  
Criado para prática de desenvolvimento de pacotes CLI, persistência de dados em JSON e organização modular.

## Funcionalidades

Adicionar objetivos de curtos ou longo prazo.

- Salvar ideias/tarefas
- Listar estes objetivos e ideias
- Lembretes periódicos definidos pelo usuário

- Criação de uma base extensível para futuras features
